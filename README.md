# Nexus Crypto Manager

Multi-cryptocurrency wallet-management application source package.

## Source package

The complete source package will be committed as `releases/Nexus-Crypto-Manager-GitHub-Source.zip` in this repository. Extract the archive to work with the source tree.

## Scope

- Non-custodial wallet-management architecture
- Address book and trusted recipient policies
- Portfolio reconciliation and accounting tools
- Security controls, backups, and read-only portfolio assistant
- No mining functionality
- No hardware-wallet integration

See `FEATURE_STATUS.md`, `SECURITY.md`, and `README.md` inside the source package for feature boundaries and setup instructions.

**Important:** This source package is not a production-audited custody application. The currently implemented native chain integration remains Solana-specific; other networks require dedicated adapters and independent testing before use with funds.
